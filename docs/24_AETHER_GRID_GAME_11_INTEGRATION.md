# AETHER GRID — одиннадцатый игровой мир OSGARD PLAY

**Статус:** интеграция подготовлена в ветке `feat/aether-grid-game-11-integration-2026-10-13`. Опубликованной считается только после успешного deploy workflow и production-проверки.

## Игровой цикл
- Пять на пять узлов: игрок поворачивает сегменты, чтобы соединить источник с ядром.
- Ежедневная доска определяется UTC-датой, поэтому игроки получают один и тот же вызов.
- Подсказка помогает исправить один узел, но добавляет три хода к результату.
- Лучший результат хранится локально в браузере; глобальный рейтинг и облачная синхронизация не заявлены.
- Кнопка «Вызвать друга» создаёт ссылку с дневным seed. Отмена системного меню не считается успешно отправленным сообщением.

## Портальная интеграция
- Каталог: `/games/`; standalone-игра: `/games/aether-grid/`; карточка подробностей: `/game/aether-grid`.
- Игровой запуск зарегистрирован в typed manifest, основном HTML-каталоге, React-каталоге, fallback Entertainment и родительском player lifecycle.
- Родитель определяет готовность по фактическим DOM-узлам `#board` и `#challenge-code`, а не по одному факту загрузки HTML.
- Завершение игры, пауза и создание приглашения передаются через существующий `osgard:game-lifecycle` same-origin контракт.
- Для приглашения сохраняется проверенная дата `og_day`; внутренний генератор создаёт карточку распространения AETHER GRID.

## Рост и монетизация
После действительно завершённой игровой сессии доступна общая межсессионная витрина OSGARD SELECT. Игрок сам выбирает сервис и может отключить промо в настройках показа. Витрина рекламирует собственные проекты OSGARD, это не подключение сторонней рекламной сети.

SHARDS — внутренняя игровая награда без денежной стоимости. Подтверждение репоста пользователем не является проверкой публикации со стороны социальной сети; не обещаем награду за подтверждённую сторонним сервисом публикацию. Денежные выплаты или погашение SHARDS за покупки не активируются этой интеграцией.
