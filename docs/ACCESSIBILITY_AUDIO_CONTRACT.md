# OSGARD accessibility, audio, and motion contract

## Accessibility

- Text scaling must preserve layout at 200%.
- Every action has a keyboard path and visible focus.
- Reduced motion removes decorative movement but keeps state feedback.
- Important visual signals have text, icon, or audio alternatives.
- Game controls support remapping where the game platform allows it.
- Mobile surfaces respect safe areas and touch target sizing.

## Audio language

- TIME: mechanical completion and civic ambience.
- SWARM: biological pulse and synchronized confirmation.
- NULL//SHIFT: digital glitch and layer-shift cue.
- INHERIT: organic ambience and memory resonance.
- REMIX: sharp arcade confirmation and creator publish sting.

Audio is feedback, not a prerequisite for understanding state. Every sound has a mute setting and does not autoplay before consent.

## Motion rules

Motion is allowed only for hierarchy, feedback, transition, or emphasis. The shared celestial motif may recur at portal transitions, season reveals, and archive milestones.
