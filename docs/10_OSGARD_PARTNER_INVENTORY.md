# OSGARD PLAY — партнёрский инвентарь и условия внедрения

Дата: 13 октября 2026 года.

## Что добавлено

- Статическая страница /games/partners/ в фирменном стиле OSGARD PLAY.
- Отдельный JSON-манифест public/games/partners/inventory.json. Он описывает форматы и их статус; новые предложения добавляются изменением данных без переписывания JavaScript.
- Фронтенд читает манифест, валидирует схему, отвергает невалидные активные/немаркированные предложения и вставляет значения через textContent.
- Форма собирает бриф локально в браузере и показывает ссылку WhatsApp. Она не отправляет запрос на сервер и не резервирует размещение.
- Страница прямо сообщает, что рекламная сеть, checkout, публичный endpoint анонимной аналитики и настоящая CMS не подключены.

## Форматы в манифесте

1. Выделение в каталоге, вне игрового поля.
2. Предложение после окончания сессии, не поверх управления.
3. Брендовый уровень/событие по согласованию с автором игры.
4. Заказная мини-игра.

Все записи имеют active: false и обязательную маркировку спонсорства. Это предложения для обсуждения, не активные рекламные размещения.

## Безопасность и измерения

- Никаких выдуманных eCPM, аудитории, показов, кликов, конверсий или рейтингов.
- UTM-метки различают источники, но не доказывают конверсию.
- Награда за видео не реализуется без провайдера и server-side reward verification.
- Браузер не подтверждает оплату. Платежи не добавлены без backend checkout, проверки подписи вебхуков, возвратов и модели прав доступа.
- Данные формы не пишутся в localStorage, не отправляются автоматически и передаются только после ручного перехода пользователя в WhatsApp.
- Это контентный манифест в репозитории, а не защищённая веб-CMS. Для управления через интерфейс нужен backend с аутентификацией и журналом действий.

## Приёмочная проверка

npm run qa:partners-page проверяет HTML-контракт, схему JSON, уникальность ID, отсутствие активных объявлений, обязательную маркировку, пользовательское подтверждение отправки, безопасный DOM-рендеринг и отсутствие несанкционированных рекламных/аналитических SDK.

Для production также нужно добавить путь /games/partners/ в route matrix. Live-доступность сайта и десяти внешних доменов не удалось подтвердить из сетевой среды, где DNS-запросы завершились ошибкой; CI route check после деплоя должен стать источником фактического HTTP-статуса.
