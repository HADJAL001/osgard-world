# CASCADE LAB 0.23.0 — Adaptive Mission Director

- Новый слой `CASCADELAB023` предлагает персональные контракты по локальному журналу: первое прохождение, восстановление после отказа, экономия деталей, скорость и стабильность.
- Засчитываются только обычные кампанийные результаты того же уровня. Daily/duel исключены; ID попытки дедуплицируется; максимум шесть попыток.
- За выполненный контракт начисляется 100 локальных Research XP. XP не является деньгами и не участвует в глобальном рейтинге.
- Контракты и летопись хранятся в браузере. Экспорт JSON выполняется по действию пользователя; сетевой сбор не добавлен.
- Ссылки для Telegram, WhatsApp, VK, X и LinkedIn формируют намерение поделиться заданием, но не подтверждают публикацию или присоединение друга.
- Приёмка: `npm run qa:cascade-lab-mission-director`, `npm run qa:games-detail`, `npm run qa:games-portal`. Production подтверждается только после успешного deploy и route matrix.
