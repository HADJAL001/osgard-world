# CASCADE LAB 0.26.0 — полный пакет OSGARD WORLD

ZIP собирается автоматически из актуального `master`; предыдущий архив CASCADE LAB 0.13.0 устарел и не содержал новые модули Replay Observatory. Метка 0.26.0 относится к Replay Observatory/PWA; основной экран сохраняет маркер 0.25.0, а service worker кэширует оболочку `v0.26.2`.

## Пять крупных блоков
1. **Игровая лаборатория:** физическая головоломка, механизмы, протоколы, телеметрия и сохранение.
2. **Исследовательские инструменты:** Hypothesis Lab, Engineering Suite, Experiment Studio, Case Passport, Trajectory X-Ray и Mission Director.
3. **Повторяемость и офлайн:** Evidence Integrity, Replay Observatory, PWA precache, локальный архив до 30 запусков и 420 кадров на запуск.
4. **Рост:** OSGARD SELECT после сессий, добровольная витрина собственных проектов, выбор сервисов, настройка частоты/отключение, приглашения и локальная награда SHARDS.
5. **Публикация и измерение:** конфигурация кампаний, снимки commerce admin/API и QA-контракты для игровых модулей и межигровой интеграции.

## Структура ZIP
- `game/` — полный каталог `public/games/cascade-lab/`, включая модули, PWA manifest, SVG и service worker.
- `portal-integration/` — связанные снимки каталога, сессионного моста, OSGARD SELECT, commerce admin/config и API.
- `source-context/` — исходники карточки игры, sitemap, Nginx и перенаправление `/entertainment`.
- `docs/` и `qa/` — документация и исходники проверок.
- `BUILD-INFO.json`, `PACKAGE-SHA256SUMS.txt` и внешний `.sha256` — метаданные источника и контрольные суммы.

## Запуск
Перейдите в `game/`, выполните `python -m http.server 4173` и откройте `http://localhost:4173/`. Service worker работает только через HTTP(S), не через `file://`.

`portal-integration/` — связанный набор файлов, а не самостоятельная копия всего сайта. Перед интеграцией обновляйте файлы по исходным путям и проверяйте diff/production routes.

## Монетизация и приватность
OSGARD SELECT — cross-promotion собственных проектов, не сторонняя рекламная сеть. SHARDS — внутриигровая единица, не деньги; ручное подтверждение репоста не доказывает публикацию. Публикацию и реферальную конверсию нельзя считать подтверждёнными без серверной валидации.

Replay Observatory хранит локальный ограниченный архив; FNV-1a fingerprints — быстрые сравнимые отпечатки, не криптографические подписи, не доказательство честности и не гарантия точности физической модели.

Пакет не доказывает миллион долларов выручки или вирусный коэффициент. Это проверяется отдельными коммерческими экспериментами и серверной аналитикой после согласия пользователя.

CI перед созданием ZIP запускает `node scripts/cascade-lab-release-bundle-smoke.mjs`, `npm run qa:games-detail`, `npm run qa:osgard-select`, `npm run qa:intermission-sponsor`, `npm run qa:game-recommendations` и smoke тест каталога, затем проверяет ZIP и SHA-256.
