# OSGARD Growth Evidence Lab

## Назначение

Путь /games/experiments/ — локальный инструмент для анализа одного заранее определённого эксперимента catalog-hero-cta-v1. Он дополняет Growth Studio и существующую коммерческую панель, но не заменяет production analytics.

## Входные форматы

- CSV с двумя строками: variant,exposures,conversions; варианты a и b.
- JSON с variants: { a: { exposures, conversions }, b: { exposures, conversions } }.
- JSON / JSONL / CSV с consented-событиями product_experiment_exposed и product_experiment_converted. Поле source должно соответствовать osgard-experiment:catalog-hero-cta-v1:<a|b>:<exposed|converted>, а событие должно иметь session_id или sessionId.
- Для событийных файлов наблюдение считается один раз на сессию/вариант. Повторные показы одной сессии дедуплицируются. Конверсии без допустимого показа исключаются с предупреждением; сессии, отнесённые к обоим вариантам, исключаются.

Загруженные файлы разбираются в памяти вкладки. Страница не вызывает сеть, не записывает сырые события в браузерное хранилище, а экспортирует только агрегаты и результат.

## Методы

- Конверсия = конверсии / показы.
- 95% интервалы отдельных долей — Wilson score.
- Интервал абсолютной разницы B − A — Newcombe interval на основе Wilson.
- Плановое число наблюдений на группу — нормальная аппроксимация для двух долей при двустороннем alpha = 0.05 и power = 0.80, заданных базовой конверсии и абсолютному MDE (п.п.).

Размер выборки является оценкой для планирования, не гарантией и не универсальным порогом качества. Эксперимент требует заранее выбранной основной метрики, корректного назначения вариантов, фиксированного срока/правила остановки и проверки защитных метрик. Нельзя объявлять причинность только на основании интервала.

## Что инструмент не делает

- Не подключается автоматически к аналитическому API и не утверждает, что импортированные данные являются production truth.
- Не показывает реальные визиты/выручку без экспорта из источника данных.
- Не запускает и не останавливает кампании, не включает объявления и не меняет посетителям варианты.
- Не отправляет пользовательские данные или файлы на сервер.
- Не является юридической или статистической экспертизой. Перед коммерческим решением проверь единицу наблюдения, рандомизацию, sample-ratio mismatch, дубли, сегменты, срок теста и business guardrails.

## Проверка

Команда npm run qa:growth-evidence проверяет математические контракты, форматы импорта, дедупликацию сессий, локальную приватность, синтаксис браузерного модуля и основные UI-маркеры.
