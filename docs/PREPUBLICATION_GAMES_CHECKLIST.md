# OSGARD Games — контрольный список перед публикацией

## Сборка и маршруты
- [ ] Pull request CI прошёл на актуальном commit: проверка TypeScript, production build, портал, NULL//SHIFT, «Империя времени» и HTML-архив.
- [ ] `/games/` открывает единый каталог; карточки всех пяти игр находят свои точки запуска и страницы `/game/:slug`.
- [ ] Проверены `/games/time`, `/games/swarm/`, `/games/null-shift/`, `/games/inherit/` и `/games/remix/`.
- [ ] Старые адреса `/entertainment` и `/games/null-shift-godot/` перенаправляют на канонический каталог/браузерную сборку.
- [ ] Все статические файлы имеют корректный MIME type; нет отсутствующих CSS/JS/изображений.
- [ ] Проверены ширины 320/375/768/1280 пикселей, keyboard focus, мобильный ввод и выход из полноэкранного режима.
- [ ] Ошибка игрового API, blocked iframe и offline не ломают каталог; отдельная ссылка на запуск остаётся доступна.
- [ ] Проверены sitemap, canonical/OG метаданные и индивидуальные страницы игр.

## Игровая телеметрия
- [ ] Сессия NULL//SHIFT начинается только после реального сообщения от рендер-цикла и заканчивается при завершении миссии.
- [ ] SWARM и REMIX сообщают фактическое начало и результат/конец раунда.
- [ ] Не считать загрузку iframe завершением игровой сессии.
- [ ] Согласие на необязательную аналитику выключено по умолчанию и проверяется вместе с авторизацией перед отправкой.

## Коммерция и право
- [ ] Внешние проекты проверены вручную перед направлением платного трафика.
- [ ] Политика конфиденциальности и условия проверены ответственным оператором/юристом и содержат данные юридического лица, применимое право и канал запросов.
- [ ] Рекламная сеть подключается только после одобрения аккаунта, проверки размещений/частоты и требований по географии/возрасту.
- [ ] Rewarded video требует добровольного выбора, серверно проверенного callback и защиты от повторной выдачи.
- [ ] Покупки/подписки не выпускаются без серверного подтверждения платежа, возвратов и серверных прав доступа.
- [ ] Форма заявки не обещает серверное сохранение, пока не подключены API/CRM, антиспам и политика хранения.

## Публикация и откат
