# Проверка содержимого React/Vite runtime — 14 октября 2026

## Почему поиск по $r.Content не даёт полный ответ

Главная страница OSGARD отдает HTML-оболочку Vite: метаданные, контейнер #root и ссылки на хешированные JavaScript-ассеты, например /assets/index-Ck8K2p_o.js. Если интерфейс строится React на клиенте, текст вроде OSGARD AI Academy может отсутствовать в корневом HTML, но присутствовать (или отсутствовать) в JS-бандле. Поэтому Select-String только по $r.Content не подтверждает наличие или отсутствие строки в готовом интерфейсе.

## Проверка production runtime

Из корня репозитория выполните:

    npm run qa:runtime-content -- "OSGARD AI Academy" "OSGARD WORLD"

Команда получает текущую HTML-оболочку, находит подключённые same-origin JavaScript-бандлы и ищет заданные строки внутри HTML и бандлов. JSON-отчёт показывает для каждой строки поля inHtml, inAssets и found. В отчёт также попадают HTTP-статусы и размеры файлов.

Чтобы команда завершалась ошибкой, если строка не найдена в HTML или начальных JS-бандлах:

    npm run qa:runtime-content -- --require="OSGARD AI Academy" "OSGARD AI Academy" "OSGARD WORLD"

Для стенда можно задать основу через переменную PowerShell $env:OSGARD_BASE_URL. Без неё используется https://osgard.world.

## Автопроверка без сети

    npm run qa:runtime-content-smoke

Smoke-тест проверяет извлечение хешированных бандлов, отличает HTML-оболочку от клиентского бандла, не скачивает сторонние скрипты, применяет таймауты и проверяет обработку отсутствующей обязательной строки и HTTP-ошибки ассета.

## Границы проверки

- Проверяется только HTML-страница и same-origin JavaScript, непосредственно подключённый из её HTML: script src и modulepreload/script preload.
- Сценарий не исследует все маршруты React, лениво загружаемые чанки, текст, создаваемый из API-ответа, контент внутри iframe и игры, загружаемые позднее.
- Отсутствие строки в начальных файлах не доказывает её отсутствие на всём сайте. Следом нужно искать в исходниках src/ и public/, а затем на конкретном маршруте.
- Проверка диагностическая и не изменяет production, не отправляет аналитику и не создаёт фиктивные события.

## Применительно к текущему выводу PowerShell

Полученный HTML показывает OSGARD WORLD в SEO/JSON-LD/noscript и сообщает имя JS-бандла index-Ck8K2p_o.js. Это нормальный результат для SPA. Он сам по себе ничего не говорит о том, включена ли строка OSGARD AI Academy в runtime-бандл.
