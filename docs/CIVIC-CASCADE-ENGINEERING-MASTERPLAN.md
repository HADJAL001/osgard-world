# CIVIC CASCADE — инженерный мастер-план OSGARD WORLD

**Текущий релиз:** 3.4.0 — повторно воспроизводимое досье решений.  
**Архитектура:** локальная детерминированная модель, ограниченный поиск, стресс-конверт и аудит доказательных данных.  
**Правило выпуска:** код в master, успешный CI и внешне подтверждённая production-версия считаются разными контрольными точками.

## 1. Главная контрольная точка

- [x] **Стресс-устойчивый поиск:** портфель решений оценивается на горизонтах T+30/T+60/T+90 и в девяти синтетических стресс-профилях.
- [x] **Осмысленные альтернативы:** Pareto-портфель показывает компромиссы риска, стоимости ресурсов, целостности слабого узла и устойчивости.
- [x] **Досье решения:** исходный снимок, версия движка, базовый прогноз, выбранный узел ремонта, кандидаты и стресс-результаты сохраняются в JSON.
- [x] **Проверка целостности:** канонический JSON и SHA-256 выявляют повреждение содержимого; явно указано, что это не цифровая подпись автора.
- [x] **Независимое повторение расчёта:** досье текущей версии заново проходит локальный поиск и стресс-анализ; сравниваются двенадцать разделов доказательного payload.
- [x] **Защита от повторного хеширования подделки:** если содержимое плана изменили и затем вычислили новый SHA-256, хеш может совпасть, но повторный расчёт выявляет несоответствие модели.
- [x] **Совместимость:** досье исторических моделей доступны только для чтения и не объявляются воспроизводимыми текущим движком.
- [x] **Порядок разработки:** этапы релизов и дальнейшие ворота разделены; каждая будущая функция имеет проверяемый критерий приёмки.
- [ ] **Production именно 3.4.0:** галочка разрешена только после успешного deploy-run и внешней проверки manifest с версией 3.4.0 на публичном маршруте.
- [ ] **OpenAI Advisor:** реальный API-слой не входит в завершённый релиз; это отдельный этап с собственными воротами безопасности и измерения пользы.

## 3. Архитектурные инварианты

1. **Единый источник истины.** Реальное действие, предварительный расчёт, стресс-анализ и повторная проверка используют один набор правил эффектов.
2. **Полный снимок для повторения.** Помимо основных метрик сохраняются операционные счётчики, время от начала операции, состояние узлов и целевой узел поиска. Если важный вход не сохранён, файл не объявляется воспроизводимым.
3. **Детерминированность.** Одинаковая модель, цель, временная точка и снимок состояния должны давать одинаковый результат поиска.
4. **Отдельные доказательства.** Структурная проверка подтверждает соответствие схеме; SHA-256 сверяет содержимое с хешем; replay-проверка подтверждает соответствие детерминированному движку. Ни одно из них само по себе не подтверждает личность автора.
5. **Честная неопределённость.** Стресс-профили — синтетические возмущения, а прогноз отражает только реализованные игровые правила. Это не физически откалиброванная модель города, не прогноз погоды и не гарантия реального исхода.
6. **Приватность.** Экспорт и проверка выполняются на устройстве. Нет скрытой загрузки файла, телеметрии или обращения к сети.
7. **Безопасное исполнение.** Импортированный файл не меняет живое состояние, не заполняет игровую очередь и не исполняет приказы.

## 4. Релиз 3.4.0 — протокол воспроизведения досье

### Что записывается
- Идентификатор движка, версия модели, версия UI и алгоритмы поиска.
- Сценарий, исходные метрики, целостность и отключения инфраструктурных узлов.
- Список активных инцидентов, время от начала симуляции и операционные счётчики, способные влиять на модель действий.
- Целевой узел ремонта, поскольку он определяет набор рассмотренных команд.
- Базовый прогноз, портфель кандидатов и все девять стресс-профилей для каждой предложенной стратегии.
- Метаданные SHA-256, сформированные отдельно от канонического payload.

### Как работает проверка
1. Ограничить размер файла одним мегабайтом, глубину JSON — 32 уровнями, число элементов — 50 000.
2. Проверить схему, версию модели, допустимые команды, целевые узлы, диапазоны ресурсов, полноту стресс-профилей и приватность.
3. Вычислить SHA-256, если поддерживается Web Crypto, и отдельно отобразить его статус.
4. Для совпадающей версии движка восстановить только копию снимка.
5. Заново выполнить поиск, прогноз и стресс-портфель; сравнить двенадцать доказательных разделов канонического payload.
6. При несовпадении отклонить статус воспроизводимости, даже если встроенный SHA-256 был пересчитан после редактирования.
7. Исторические версии оставить в режиме аудита без принудительного сравнения с текущими правилами.

### Ограничения
Replay подтверждает, что текущая реализация воспроизводит представленный набор вычислений из записанного состояния. Он не доказывает соответствие игры реальному миру и не защищает от злонамеренной замены самого кода движка. Для подтверждения авторства нужна отдельная подпись доверенным ключом; SHA-256 не является подписью.

## 5. Контрольный список релиза

### Код и локальные регрессии
- [x] JavaScript встроенной страницы разбирается без синтаксических ошибок.
- [x] HTML-маркеры и manifest поддерживают единую версию.
- [x] Поиск ограничен по глубине, ширине, длине команды и числу стресс-кандидатов.
- [x] Все девять синтетических профилей проверяются на полноту и монотонность.
- [x] Успешное досье текущей модели воспроизводит тот же портфель.
- [x] Отредактированное и повторно захешированное досье не проходит replay.
- [x] Исторические версии остаются доступными в read-only режиме.
- [x] Импорт не исполняет приказы, не меняет состояние и не делает сетевых запросов.
- [ ] Реальное выполнение Node smoke и GitHub Actions должно завершиться без регрессий.
- [ ] Внешний production deploy и route matrix должны подтвердить именно версию 3.4.0.

### Release gate
Номер версии считается опубликованным только после успешного deployment workflow и внешней проверки публичного manifest. Если CI не запускался или внешний маршрут недоступен для проверки, статус остаётся «не подтверждён».

## 7. Измеряемые показатели

- Время обычного поиска и replay-проверки.
- Количество изученных очередей и стресс-кандидатов.

- Расхождение реального исполнения и прогноза в контролируемых сценариях.
- Стоимость, задержка и измеримое улучшение решений для будущего OpenAI Advisor.

Не называть synthetic score доказательством качества реальной городской модели и не называть число открытий страницы конверсией.
