# CASCADE LAB PWA 0.26.0 — Offline Field Device

## Что изменилось

- CASCADE LAB можно установить как веб-приложение на совместимом настольном или мобильном браузере.
- Добавлены Web App Manifest, иконка и подсказки по установке. На iPhone/iPad — Safari → «Поделиться» → «На экран Домой»; на других устройствах — меню браузера.
- Service worker заранее сохраняет оболочку и восемь диагностических модулей, отдаёт свежую страницу при наличии сети и использует локальную оболочку при офлайн-запуске.
- Кэш ограничен путём `/games/cascade-lab/`, не перехватывает другие домены, не кэширует POST и не обрабатывает аналитику или платежи.
- Прогресс, исследования, паспорта и рекорды остаются локальными для браузера/устройства. Внешние ссылки требуют интернет.
- Это веб-приложение, а не нативная сборка для App Store или Google Play.

## Приёмка

`npm run qa:cascade-lab-pwa` проверяет manifest, icon, список precache, границы кэша и симулирует установку service worker, очистку старого кэша и офлайн-загрузку.

Публичная доступность подтверждается после CI и HTTP-проверки `/games/cascade-lab/`, `/games/cascade-lab/manifest.webmanifest`, `/games/cascade-lab/service-worker.js` и `/games/cascade-lab/lab-icon.svg`.
