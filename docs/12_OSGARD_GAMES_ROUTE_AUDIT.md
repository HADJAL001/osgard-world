## Архитектура
- Основной сайт: React 19, TypeScript, Vite 6.
- Игровая витрина: самостоятельная адаптивная HTML/CSS/JS-страница с поиском, фильтрами, избранным, недавними играми и встроенным игроком.
- Каталог содержит восемь игр: Империя времени, SWARM, NULL//SHIFT, INHERIT, REMIX, CIVIC CASCADE, PATINA Atelier и SIGNAL RUN.
- Игры используют разные рантаймы (React, самостоятельные веб-клиенты, Unity WebGL, Godot); унификация движка не требуется.
- В исходниках есть локальная финансовая модель, спонсорский инвентарь, consent-aware аналитика и GitHub Actions для сборки, проверки и выкладки.

3. В каталоге вторичные действия CIVIC CASCADE и PATINA ведут на отдельные страницы описания. Добавлены тесты, защищающие это поведение.

## Монетизация: подтверждённые границы
- Финансовая модель рассчитывает сценарии на заданных допущениях, а не отражает реальные рекламные доходы.
- Спонсорский инвентарь не доказывает, что рекламная сеть уже подключена.
- В просмотренных исходниках нет подтверждения готового внешнего платёжного провайдера с серверной валидацией. До настройки провайдера нельзя заявлять, что реальные покупки или подписки работают.
- Наличие аналитических событий не доказывает, что production API доступен и получает их в реальном трафике.

## Публикация и ограничения
- Эта проверка основана на исходниках GitHub и smoke-контрактах. Визуальный production URL не удалось независимо проверить через доступный веб-инструмент.
- Изменения в этой ветке не переключают production напрямую. CI должен пройти до слияния; затем существующий workflow выкладки выполняет проверку опубликованных маршрутов и same-origin API.
- В `DEPLOYMENT.md` указаны секреты выкладки `OSGARD_DEPLOY_HOST`, `OSGARD_DEPLOY_USER` и `OSGARD_DEPLOY_KEY`. Перед дальнейшими изменениями инфраструктуры нужны проверка staging и подтверждённый rollback.

## Следующие приоритеты

2. Сверить production route-matrix после выкладки, включая новые detail-страницы.

4. После появления фактического трафика анализировать реальные старты, завершения и переходы; не смешивать их с модельными прогнозами.
