# CIVIC CASCADE — интеграция в OSGARD PLAY

Дата подготовки: 13 октября 2026 года.

## Что добавлено

- Отдельная браузерная игровая точка входа: /games/civic-cascade/.
- Карточка CIVIC CASCADE в каталоге /games/ с поисковыми терминами, тегами жанра, избранным и стандартной кнопкой запуска.
- Поддержка стандартного игрового диалога OSGARD: запуск во встроенном окне, полноэкранный режим, закрытие сессии и жизненный цикл в public/games/player-lifecycle.js.
- Идентификатор civic-cascade зарегистрирован в src/core/manifest.ts.
- Статический smoke-тест проверяет страницу, действия, игровой жизненный цикл, структуру каталога и скрипт игры.
- Страница включена в XML sitemap.

## Содержание Web Edition

Это самостоятельная облегчённая веб-редакция, написанная на HTML/CSS/Canvas без сторонних библиотек и без серверных ключей. Она не подменяет оригинальный архив CIVIC CASCADE 1.8.0 и не выдаётся за нативную Godot-сборку.

Внутри доступны три сценария: ливень и подтопление, каскадный сбой энергосети и перекрытие дорог. Игрок расходует ограниченные ресурсы на насосы, стабилизацию энергосети, маршруты и ремонт выбранного узла. Течение операции обновляет воду, мощность сети, доступность маршрутов, риск и цели; игра поддерживает паузу, 1×/1.5×/2×, сброс операции, мышь и сенсорное управление.

Встраиваемый клиент посылает родительскому окну событие same-origin osgard:game-lifecycle со статусами started и completed; произвольные внешние адреса не подключаются. Показатели относятся только к игровой модели и не являются реальными городскими измерениями. Серверная аналитика, рекламные показы, платежи, облачные сохранения и онлайн-режим не добавлены.

## Проверки перед слиянием

- Проверить, что новый файл существует и HTML содержит нужные точки входа.
- Выполнить npm run qa:games-portal.
- Выполнить npm run check и npm run build.
- Проверить вручную на компьютере и телефоне: каталог → карточка → запуск → полноэкранный режим → закрытие.
- Проверить конец успешной и неуспешной операции, смену сценария, паузу, скорость и ресурсы.
- После публикации убедиться, что https://osgard.world/games/civic-cascade/ отдаёт HTML, а браузер не показывает ошибок.

## Публикация

Файлы подготовлены в ветке feat/civic-cascade-games-integrated. Для production необходимы успешный CI, ревью и слияние изменений в основную ветку с последующим штатным развёртыванием. Само наличие pull request не означает, что опубликованный сайт уже обновлён.
