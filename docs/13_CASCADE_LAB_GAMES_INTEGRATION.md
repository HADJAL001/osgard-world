# CASCADE LAB — интеграция в OSGARD WORLD GAMING

## Канонические адреса
- Каталог игр / раздел «Развлечения»: https://osgard.world/games/
- Страница игры: https://osgard.world/game/cascade-lab
- Самостоятельный запуск: https://osgard.world/games/cascade-lab/

## Обновление 0.13.0
- В `public/games/cascade-lab/index.html` интегрирована автономная сборка CASCADE LAB 0.13.0 — без отдельного CDN и дополнительного игрового runtime.
- Сохранён контракт готовности iframe через `body[data-cascade-lab-ready="true"]` и сообщения `osgard:game-lifecycle`: ready, started, paused, resumed.
- Страница сохраняет встроенную витрину OSGARD между протоколами: выбор кампании, кнопка перехода, Telegram/WhatsApp/VK/X/LinkedIn и ручное подтверждение вознаграждения +10 LC (не более раза в день по UTC).
- Внешняя страница портала содержит каталог девяти игр; CASCADE LAB остаётся в нём под номером 09. Путь /entertainment продолжает перенаправлять на единый каталог /games/.
- Для межсессионной витрины используется существующий скрипт игрового портала и его настройки предпочтений показа.

## Измерения и границы
- Награда +10 LC подтверждается игроком вручную. Соцсеть не подтверждает игре факт опубликованного поста; это не доказательство публикации и не основание для денежных выплат.
- События родительской игровой панели отправляются через существующую серверную аналитику только при разрешённом согласии. Локальные показатели не считаются глобальными пользователями или настоящим коэффициентом вирусности.
- Рекламная витрина — cross-promotion собственных проектов OSGARD, а не подключение сторонней рекламной сети.
- Платежи не подключены. Внутриигровой набор основателя помечен как планируемый.
- Диагностические показатели относятся к игровой физической модели, а не к сертифицированным инженерным измерениям.

## Приёмочная проверка
CI запускает `npm run qa:games-detail`, `npm run qa:games-portal`, `npm run build` и матрицу production-маршрутов. Публикация считается проверенной только после успешного GitHub Actions deployment и контрольного запроса к production URL.
