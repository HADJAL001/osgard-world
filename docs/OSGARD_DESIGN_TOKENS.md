# OSGARD design contract

This contract turns brief section 10-12 into implementation rules shared by portal, games, and future products.

## Palette

- Obsidian `#05070B`: page foundation and deep overlays.
- Midnight `#08111F`: panels and product surfaces.
- Deep Navy `#0B1730`: interactive stage backgrounds.
- Electric Blue `#4E9CFF`: active system state and links.
- Cyan `#53D7FF`: live/co-operative signal.
- Champagne `#D7B978`: premium action and OSGARD identity.
- White `#F5F7FA`: primary readable text.
- Muted `#8B95A7`: secondary text and metadata.

## Type roles

- Display: Cormorant Garamond for world names and editorial moments.
- Interface: Inter/Jost for controls and navigation.
- Data: JetBrains Mono for IDs, scores, states, and telemetry labels.

## Component rules

- A product card must expose identity, state, one proof point, and one action.
- A live state uses blue/cyan; a premium action uses champagne; errors must not use the brand accent as decoration.
- Motion communicates hierarchy, feedback, transition, or emphasis only.
- Every new surface must remain usable at 320px width and with reduced motion enabled.
