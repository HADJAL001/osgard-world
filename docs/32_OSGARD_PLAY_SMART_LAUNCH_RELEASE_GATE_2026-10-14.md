# OSGARD PLAY — Smart Launch and Release Gate
Дата: 14 октября 2026 года
Репозиторий: `HADJAL001/osgard-world`
Ветка производительной доработки: `perf/games-lazy-webgl-capability-check-2026-10-14`

## Задача
Портал уже содержит 11 игр, поиск и жанры, избранное/историю, окно запуска, рекомендации, Player Console, PWA и согласуемую аналитику. Smart Launch усиливает первое решение игрока: помогает выбрать игру, не обещая поддержку или скорость, которую мы не измеряли.

## Что реализовано
- Локальная проверка сенсорного ввода, offline-состояния, доступных browser hints для экономии данных/медленной сети и reduced motion выполняется при показе панели. Создание WebGL-контекста — только по явному нажатию, чтобы не блокировать первый экран на мобильных устройствах.
- Профиль повышенной WebGL-нагрузки назначается только NULL//SHIFT и REMIX; остальные игры не объявляются «лёгкими», совместимыми или протестированными без фактов.
- Предлагается стартовая игра и обратимый фильтр для двух отмеченных тяжёлых WebGL-профилей.
- Игры не блокируются автоматически: пользователь всегда может отключить фильтр и запустить их вручную.
- Статусы показываются на карточках каталога; панель адаптируется к телефону и сообщает об изменении статуса через aria-live.
- Проверка WebGL 2/WebGL 1 создаёт контекст только после нажатия «Проверить совместимость». При загрузке каталога GPU-контекст не создаётся. Все проверки локальны: без fetch, cookies, localStorage/sessionStorage, аналитики или отправки характеристик устройства.
- Новые JS/CSS входят в minify/precompression, проверку PWA-оболочки, проверки iOS payload и release readiness.
- Service worker cache обновлён до v1.0.1; добавлена синтаксическая проверка через Node `--check` и парсер smoke-теста, чтобы не пропустить некорректный список precache.

## Ограничения
Это подсказка совместимости, а не benchmark, тест GPU, доказательство сенсорного управления внутри конкретной игры или гарантия запуска. Некоторые браузеры скрывают memory/network hints. Пользователь может вручную запускать любой игровой профиль.

## Проверка
```sh
npm run qa:device-fit
npm run qa:pwa
npm run qa:games-assets
npm run qa:ios-appstore
npm run check
npm run build
npm run qa:release
```

Ни рекламная сеть, ни платежи этим изменением не включаются. Коммерческая готовность отслеживается отдельно через защищённый Commerce Admin.
