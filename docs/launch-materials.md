# OSGARD launch materials

## Telegram bot: @OSGARD_world_bot

### Entry flow

1. `/start` welcomes the user, selects RU or EN and creates an Imperial ID.
2. The main menu shows `Worlds`, `TimeCoin`, `Status`, `Support` and `Account`.
3. `Worlds` lists seven products with a verified deep link to each product.
4. `TimeCoin` shows the balance, status, available activity and redemption rules before confirmation.
5. `Status` shows progress across the seven worlds and what unlocks the next level.
6. `Account` provides language, data and notification settings. No bonus is offered for passive activity.

### Commands

`/start` -- create or open account.  
`/worlds` -- products and links.  
`/wallet` -- TimeCoin balance and history.  
`/status` -- Guest, Guardian, Duke, Master or Architect.  
`/support` -- support entry point.  
`/rules` -- current TimeCoin Rules.  
`/language` -- Russian or English.

The bot must ask for consent before linking product identifiers, must show the reason for each accrual, and must record idempotency keys for every balance operation.

## TimeCoin economics: model for 1,000 active users

Use this only as an internal scenario, not as a marketing claim. It requires actual product cost and conversion data before publication.

Assumptions: 1,000 monthly active users; average 0.08 TC granted per active user per month; 80 TC issued in total; 20% redemption rate in the month; average internal cost of a redeemed TC benefit is $1.00; $10 is only the programme reference value, not a cash conversion rate.

| Indicator | Scenario |
| --- | ---: |
| TimeCoin accrued | 80 TC |
| Benefits redeemed | 16 TC |
| Internal redemption cost | $16 |
| Gross subscription revenue uplift | must be measured |
| Retention uplift | must be measured against a control cohort |

The economics must be recalculated from actual cohort retention, redemption, service cost and abuse rate. Never use TimeCoin as a promise of income or an externally exchangeable value.
