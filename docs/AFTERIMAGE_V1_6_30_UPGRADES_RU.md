# AFTERIMAGE//RUN v1.6.0 — 30 улучшений

Это список изменений именно в текущем PR, а не список пожеланий. Статистика и достижения хранятся локально; публичный рейтинг не имитируется.

## Игровой цикл и физика
1. **Подбор защитного PHASE SHIELD.** Примерно 12% сгенерированных подборов — редкий щит вместо обычного сигнал-осколка.
2. **Одна зарядка щита максимум.** Игрок не может копить неограниченное число защитных зарядов.
3. **Защита от одного столкновения.** Заряд поглощает удар, даёт короткую неуязвимость и позволяет продолжить забег.
4. **Отдельная визуальная форма щита.** Золотой шестиугольник с крестом отличим от голубого осколка даже без текста.
5. **Повторный щит не пропадает впустую.** Если заряд уже полный, подбор превращается в +40 бонусных очков.
6. **Бонус за near-miss.** Чистый проход рядом с препятствием даёт +75 очков.
7. **Near-miss повышает комбо.** Рискованный, но чистый манёвр усиливает следующий результат.
8. **Исправлена граница вызова.** Результат, равный целевому счёту, считается выполненным челленджем (>= вместо >).

## Карьерный профиль и удержание
9. **Карьерная панель.** Встроенная статистика показывает реальные данные этого браузера.
10. **Счётчик стартов.** Отдельно учитываются начатые забеги.
11. **Счётчик завершённых забегов.** Поражение после столкновения не стирает историю результата.
12. **Разделение тренировочного и рейтингового режимов.** Practice не влияет на официальный локальный рекорд и соревновательные достижения.
13. **Текущая серия дней.** Streak обновляется максимум один раз в UTC-день.
14. **Лучшая серия дней.** Сохраняется личный longest streak.
15. **Суммарная дистанция.** Учитываются метры во всех локально сохранённых забегах.
16. **Сумма сигнал-осколков.** Карьерный счётчик показывает фактически собранные осколки.
17. **Счётчик PHASE DASH.** Сохраняется число использованных рывков.
18. **Личный рекорд карьеры.** Отдельно хранится лучший рейтинговый результат за всё время.
19. **Последние забеги.** В localStorage сохраняются до 10 результатов, интерфейс показывает последние пять.
20. **Девять достижений.** FIRST SIGNAL, 2 KM PILOT, SHARD HUNTER, PHASE DANCER, COMBO MASTER, 3-DAY STREAK, CHALLENGE BREAKER, SIGNAL CARRIER и TEN RUNS.
21. **Автоматическое получение достижений.** Значки выдаются по сохранённым условиям, без фиктивной глобальной таблицы.
22. **Подтверждённая награда за приглашение учитывается в профиле.** Простое открытие соцсети или копирование ссылки не объявляется подтверждённой публикацией.

## Графика, производительность и диагностика
23. **Режим Eco Graphics.** Добавлен переключатель для слабых устройств.
24. **Адаптивный backing scale.** Eco ограничивает разрешение Canvas, экономя графическую память.
25. **Упрощённый звёздный фон.** В Eco рисуются 65 фоновых звёзд вместо 150.
26. **Сокращённые вспышки частиц.** Эко-режим ограничивает размер эффектов столкновения и подбора.
27. **Жёсткий лимит частиц.** Буфер визуальных частиц не растёт бесконечно и обрезается до 320 элементов.
28. **Измерение времени кадра.** Во время забега считаются общее количество кадров, среднее и максимальное время кадра.
29. **Учёт медленных кадров.** В JSON-отчёт входят кадры длительностью более 34 ms, число near-miss, бонусные очки, подобранные щиты, состояние профиля и достижения.
30. **Run report schema v2 и очистка аудио.** Диагностический JSON помечен версией игры 1.6.0; Web Audio context закрывается при pagehide, сохранённые числовые поля профиля нормализуются, а Canvas не изменяет размер дважды при старте.

## Монетизация и рост — без фальшивых показателей

- Текущий путь роста: вызов друга по daily seed → повторный запуск → сравнение результатов → добровольный repost → отдельное подтверждение получения локальной косметической SIGNAL SHARD.
- SIGNAL SHARD не влияет на счёт, не продаётся и не имеет денежной ценности. Клиентское localStorage не является защитой от мошенничества.
- В межигровой паузе используется существующий OSGARD SELECT: выбор проекта и возможность пропуска. Собственные проекты обозначаются как cross-promotion, а не поддельные сторонние рекламные показы.
- Не включены рекламная сеть, оплачиваемая referral-награда, платёжный checkout или подписка. Для rewarded ads нужна одобренная сеть, явное добровольное согласие, серверная проверка callback и дедупликация; для денежных рефералов — серверная атрибуция и защита от злоупотреблений.
- $1 000 000 — цель, не прогноз. До масштабирования надо измерить долю игроков, которые заканчивают забег, повторяют его на следующий день, делятся ссылкой, приводят новых игроков и конвертируются в реальный бизнес-результат.

## Гейт релиза
После изменений должны пройти npm run build, npm run qa:games-portal, npm run qa:ecosystem и npm run qa:production-routes. Публикация на osgard.world подтверждается только после успешного self-hosted deploy job и проверки production URL.
