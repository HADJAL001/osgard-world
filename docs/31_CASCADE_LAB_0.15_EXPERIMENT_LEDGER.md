# CASCADE LAB 0.15.0 — личный журнал экспериментов

Дата: 14 октября 2026 года.
Поверх существующей версии 0.14.0 добавлен отдельный встроенный слой журнала. Сама физика и инженерная консоль сохранены; библиотек и внешних CDN не добавлено.

## 30 улучшений

1. У версии игры есть единый маркер 0.15.0 для портала и production route check.
2. В верхней панели появился прямой вход в личный журнал.
3. Журнал записывает результат при переходе экрана результата из скрытого состояния в видимое.
4. Записываются и успешные, и неудачные попытки.
5. Для записи сохраняется название текущего протокола.
6. Класс результата принимается только из разрешённого набора оценок.
7. Игровое время извлекается из сообщения результата и ограничивается безопасным диапазоном.
8. Количество установленных устройств сохраняется только после проверки диапазона.
9. Время записи нормализуется в ISO/UTC.
10. Для каждой записи используется отдельный ID; дубликаты отбрасываются при чтении и импорте.
11. История ограничена 200 последними записями.
12. Повреждённое или запрещённое localStorage не блокирует запуск самой игры.
13. В журнале отображается число попыток.
14. Отдельно отображается количество успешных завершений.
15. Отдельно отображается количество неудач.
16. Рассчитывается доля успехов на основе фактической локальной истории.
17. Показывается число уникальных протоколов, встречающихся в истории.
18. Рассчитывается лучшее записанное время.
19. Добавлена шкала последних 12 записей; цвет отображает исход, высота — записанную длительность.
20. Есть текстовый поиск по названию протокола и тексту результата.
21. Есть фильтры всех, успешных и неудачных попыток.
22. Историю можно сортировать по времени, длительности и классу результата.
23. Шесть достижений вычисляются только из сохранённых персональных результатов.
24. Одну запись можно удалить отдельно, не меняя игровые сохранения.
25. Полное удаление журнала требует подтверждения и не очищает сохранение самой игры.
26. JSON-экспорт включает схему, её версию, время экспорта и записи.
27. CSV-экспорт содержит поля времени, уровня, исхода, класса, длительности, количества устройств и заметки.
28. CSV-значения, которые похожи на формулы таблиц, экранируются перед экспортом.
29. Импорт JSON проверяет имя схемы, версию, типы, временные значения, лимит 200 KiB и не более 200 записей; неправильные и повторяющиеся записи пропускаются.
30. Для отдельного результата добавлены Web Share API и резервное копирование в буфер обмена; отмена не считается завершённой отправкой. Клавиша J открывает журнал, фокус возвращается на кнопку после закрытия, состояние объявляется через live region, интерфейс адаптируется к узкому экрану и учитывает reduced motion.

## Приватность и ограничения

- История хранится только в localStorage данного браузера. Она не передаётся на сервер и не зависит от согласия на игровую аналитику.
- Экспорт возникает только после нажатия игрока. Игровой журнал не содержит email, телефон, токены, ID авторизации или историю серверной аналитики.
- Сообщение родительскому окну о действии share отправляется только после успешного разрешения системного меню отправки либо копирования в буфер. Это подтверждает действие браузера, а не публикацию поста; соцсеть не предоставляет игре проверку факта поста.
- История и достижения личные, локальные. Они не являются глобальным рейтингом, не подтверждают число пользователей или сетевую популярность.
- 0.15.0 не подключает платёжный процессинг и не вводит денежное вознаграждение за репост.

## Контроль качества

- `npm run qa:games-detail` проверяет заголовок/маркер версии, уникальность слоя 0.15.0, синтаксис слоя, наличие основных контрактов, лимиты импорта, локальное хранилище и отсутствие динамического `innerHTML`.
- `npm run qa:production-routes` ожидает заголовок CASCADE LAB 0.15.0 и маркер экспериментов в реальном HTML ответа.
- Успешный smoke-тест подтверждает статические контракты, но не заменяет ручной запуск Chrome/Safari/iOS/Android. Production доступность подтверждается только результатом deployment и route matrix.
