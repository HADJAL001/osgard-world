YOUR CHOICE / ANALYTICS

Настройки аналитики

Выбор сохраняется только в этом браузере. Эта страница настроек не отправляет аналитические события и не загружает сторонние трекеры.

Аналитика выключена

Вы можете изменить решение в любой момент. При отключении ожидающие события удаляются из локальной очереди этого браузера. Запрос, уже полученный сервером до отзыва, нельзя удалить этим действием.

1. Область действия

Документ описывает каталог osgard.world/games/. У отдельных игр могут быть собственные API, сохранения и условия. INHERIT хранит состояние локально, сетевые режимы SWARM и REMIX зависят от своих серверов.

2. Локальное хранение

Каталог использует localStorage: osgard.games.favorites.v1 (избранное), osgard.games.recent.v1 (последние игры) и osgard.games.analytics-consent.v1 (выбор аналитики). Каталог сам по себе не отправляет эти значения серверу. Их можно очистить в браузере.

3. Необязательная аналитика

Необязательная аналитика выключена по умолчанию. Если вы явно разрешили её, настроенный Commerce API OSGARD может получать ограниченный список событий: просмотр каталога/страницы Premium/партнёрской страницы, запуск и завершение игровой сессии, переход по промо-ссылке и событие отправки заявки. Передаются случайный идентификатор события для защиты от повторной записи, псевдонимный идентификатор сессии, идентификатор игры, источник, путь страницы без query-параметров и длительность. Поля заявки, email, телефон и токен входа не входят в записи этой таблицы событий. Отдельные авторизованные игровые события могут отправляться в /api/v1/player/events с токеном учётной записи — это другой поток данных.

События Commerce API удаляются через 90 дней по умолчанию после получения; оператор может настроить срок от 30 до 365 дней переменной ANALYTICS_RETENTION_DAYS. Очистка запускается при старте API и затем каждые шесть часов, если база данных доступна. Эти правила вступают в силу на развёрнутом и настроенном сервере; при отсутствии рабочей базы события не сохраняются. Если API временно недоступен, уже согласованные события могут ожидать отправки в локальной очереди браузера: максимум 100 событий и срок не более 7 дней. При восстановлении соединения каталог повторяет отправку; сервер использует ID события для защиты от повторной записи. При отзыве согласия очередь удаляется. Если хранилище браузера недоступно, события не накапливаются. Каталог не подключает рекламные пиксели, сторонние аналитические скрипты или внешние шрифтовые CDN. UTM-параметры на исходящих ссылках обозначают источник перехода, но не подтверждают конверсию на сайте назначения.

Межигровые подборки сервисов OSGARD помечаются как самореклама собственных проектов, не являются сторонней рекламной сетью и открываются только при добровольном выборе пользователя. Для ссылок-приглашений дополнительная аналитика работает только при явно включённом согласии. При инициировании приглашения браузер может сохранить случайный токен владельца и код приглашения локально; сервер хранит SHA-256 хеш токена, код приглашения, игру и состояние квалификации награды. Для косметической награды нужны открытие приглашения и запись сервером начала и завершения игровой сессии длительностью не менее 30 секунд. Такие события помогают ограничить повторы, но не доказывают уникальную личность пользователя или настоящий публичный репост. Записи приглашений удаляются согласно настроенному сроку хранения аналитики (ANALYTICS_RETENTION_DAYS, по умолчанию 90 дней). SHARDS — локальные косметические очки без денежной стоимости. Поделиться ссылкой можно и без включения аналитики; в этом случае серверная атрибуция и награда не работают.

3.1. Необязательный AI Game Coach

AI Game Coach не запускается автоматически и выключен, пока оператор не активирует его в серверной конфигурации. Для каждого запроса пользователь отдельно отмечает согласие и нажимает кнопку. Сначала сайт проверяет, включена ли функция; если нет, сводка игровой сессии не отправляется.

При включённом AI Coach сервер передаёт OpenAI API только разрешённые поля: идентификатор игры, язык интерфейса, длительность и факт завершения сессии; счёт/ошибки добавляются только если игра передала допустимые числовые значения. Имя, email, токен входа, ID сессии, код приглашения и свободный пользовательский текст не включаются. API-запрос использует store: false; это отключает сохранение объекта ответа как состояния Responses API, но не заменяет ознакомление с действующими условиями и настройками обработки данных OpenAI. Ответ подсказки не сохраняется в профиле OSGARD и не меняет игровые очки, SHARDS, сложность или платежи.

Ключ OpenAI хранится только в окружении серверного Commerce API и не публикуется в браузерном коде. Функция ограничена по частоте запросов, а при отсутствии ключа, отключённом флаге или ошибке игрок может продолжить игру без AI Coach. Необязательная аналитика OSGARD и согласие на разовый запрос AI Coach — разные настройки.

4. Заявки

При явном согласии и доступном API форма передаёт тип проекта, необязательный бюджет, предоставленный контакт и описание задачи серверу OSGARD для ответа на обращение. Если API недоступен, форма предлагает подготовленный текст WhatsApp; он не отправляется автоматически, и вы сами решаете, отправлять ли его. Переписка по email/WhatsApp обрабатывается соответствующими сервисами.

5. Реклама и покупки

Рекламная сеть и вознаграждаемая реклама не подключены. Код платёжного checkout существует, но обработка платежей доступна только после настройки серверных ключей, цен, вебхука и базы; live-платежи и продажа подписки по умолчанию выключены.

6. Хранение и контакт

Избранное и история игр остаются в localStorage до очистки браузера. Для согласованных событий Commerce API используется срок хранения, описанный выше; иные игровые API и инфраструктурные журналы могут иметь собственные настройки и сроки. Контакт: osman.osmanov0099@gmail.com.

Перед коммерческим запуском оператор должен проверить применимое право, указать юридические реквизиты и проверить все сроки хранения, потоки данных и механизмы отзыва согласия.

7. Заявки, покупки и платёжный провайдер

Если вы отмечаете согласие и отправляете заявку, на настроенный сервер OSGARD могут передаваться тип проекта, необязательный бюджет, предоставленный контакт и описание задачи для ответа на обращение. Если API недоступен, форма предлагает подготовленный текст WhatsApp, который вы отправляете сами.

При доступном checkout сведения о заказе (email, товар, идентификатор платёжной сессии, статус и суммы) обрабатываются сервером OSGARD. Интеграция передаёт необходимые сведения платёжному провайдеру. Реквизиты карты и CVC вводятся на стороне платёжного провайдера; OSGARD не предназначен для их сбора или хранения. Фактическая обработка зависит от конфигурации активного сервиса.

Необязательная аналитика отправляется только после явного согласия. Она ограничена именем события, псевдонимным идентификатором сессии, игрой, источником, путём страницы и длительностью. Согласие можно изменить выше или на страницах каталога, содержащих соответствующие настройки. Рекламная сеть пока не подключена. Перед коммерческим запуском оператор должен опубликовать юридические реквизиты, сроки хранения и контакт по вопросам данных.

Только после явного согласия на аналитику браузер может локально хранить время фактической видимости спонсорской карточки в ключе osgard.games.sponsor-exposures.v1 до 24 часов. Без согласия спонсорские карточки могут отображаться без постоянного локального ограничения частоты; события показа и перехода при этом не сохраняются и не отправляются. После согласия, если браузерное хранилище недоступно, рекламный блок скрывается, поскольку частотный лимит нельзя надёжно применить. При включённой аналитике события поступают в очередь и отправляются серверу только при сохранённом согласии. Лимит работает только в данном браузерном хранилище и не гарантируется между устройствами. Публичный блок остаётся скрытым, пока Commerce API не настроен.
