OSGARD PLAYPRIVACY / 01

OSGARD WORLD / GAMES

Конфиденциальность
по умолчанию.

Дата редакции: 13 октября 2026 года

Главное: каталог не подключает рекламную сеть и не отправляет аналитику по умолчанию. Избранное и история хранятся локально в браузере.

1. Область действия

Документ описывает каталог osgard.world/games/. У отдельных игр могут быть собственные API, сохранения и условия. INHERIT хранит состояние локально, сетевые режимы SWARM и REMIX зависят от своих серверов.

2. Локальное хранение

Каталог использует localStorage: osgard.games.favorites.v1 (избранное), osgard.games.recent.v1 (последние игры), osgard.games.invite-code.v1 (случайный код для персональной ссылки-приглашения) и osgard.games.analytics-consent.v1 (выбор аналитики). Код приглашения не содержит имени или контактов и остаётся в браузере. Его можно удалить, очистив локальные данные сайта.

3. Необязательная аналитика

Аналитика выключена по умолчанию. Если вы явно включаете её и вошли в OSGARD, каталог может отправить события game_opened или share_created в same-origin API /api/v1/player/events. Событие содержит действие, игру, время и источник каталога. Запрос выполняется с существующим токеном входа. Без согласия или токена запрос не отправляется. Для приглашений действует такое же требование явного согласия: при включённой аналитике и доступном Commerce API могут передаваться события создания ссылки и открытия страницы по коду вида OSG-XXXXXXXX. В событии указывается случайный код приглашения, имя события и псевдонимный идентификатор сессии; имя и контакты приглашающего не собираются. Без согласия referral-события не отправляются, код из URL не сохраняется в аналитическое хранилище браузера.

Каталог не подключает рекламные пиксели, сторонние аналитические скрипты или шрифтовые CDN. Ссылки на проекты OSGARD имеют UTM-параметры; обработка на целевых сайтах регулируется их собственными правилами.

4. Заявки

При заполнении заявки и явном согласии настроенный API OSGARD может получить тип проекта, необязательный бюджет, указанный контакт и описание задачи, чтобы команда ответила на обращение. Если API недоступен или не принимает заявку, страница предлагает открыть подготовленный текст в WhatsApp; вы сами решаете, отправлять ли его. Переписка по email/WhatsApp обрабатывается соответствующими сервисами.

5. Реклама и покупки

В этой версии каталог не подключает рекламного провайдера или платёжный checkout. Если они появятся, документ необходимо обновить до запуска.

6. Хранение и контакт

Локальные значения остаются в браузере до очистки. Срок хранения серверных событий определяется backend OSGARD; код каталога не даёт оснований заявлять конкретный срок. Контакт: osman.osmanov0099@gmail.com.

Перед коммерческим запуском оператор должен проверить применимое право, установить юридические реквизиты и конкретные сроки хранения.

6. Заявки, покупки и платёжный провайдер

Если вы отмечаете согласие и отправляете заявку, на настроенный сервер OSGARD могут передаваться тип проекта, необязательный бюджет, предоставленный контакт и описание задачи для ответа на обращение. Если API недоступен, форма предлагает подготовленный текст WhatsApp, который вы отправляете сами.

При доступном checkout сведения о заказе (email, товар, идентификатор платёжной сессии, статус и суммы) обрабатываются сервером OSGARD. Интеграция передаёт необходимые сведения платёжному провайдеру. Реквизиты карты и CVC вводятся на стороне платёжного провайдера; OSGARD не предназначен для их сбора или хранения. Фактическая обработка зависит от конфигурации активного сервиса.

Необязательная аналитика отправляется только после явного согласия. Она ограничена именем события, псевдонимным идентификатором сессии, игрой, источником, путём страницы и длительностью. Согласие можно отозвать в настройке аналитики каталога. Рекламная сеть пока не подключена. Перед коммерческим запуском оператор должен опубликовать юридические реквизиты, сроки хранения и контакт по вопросам данных.
