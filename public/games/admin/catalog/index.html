каталога.

Управляйте карточками уже зарегистрированных игр без изменения HTML. URL запуска защищены серверным allow-list и не редактируются в этой панели. Добавление нового игрового клиента по-прежнему требует кода, сборки и QA.

Граница безопасности. Эта страница сама по себе не является приватной — её защищает только noindex от поисковой индексации. Запись и чтение каталога выполняются сервером с Bearer-токеном оператора. Токен хранится только в памяти текущей вкладки и не записывается в браузерное хранилище. До настройки API страница останется в режиме чтения/предупреждения.
