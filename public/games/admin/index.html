API STATUS / НЕ ПОДКЛЮЧЁН

Доступ оператора

Введите серверный MODERATION_ADMIN_TOKEN. Он хранится только в памяти этой вкладки и передаётся в заголовке X-Moderation-Token на same-origin API. Не вводите Supabase user token, пароль или платёжный ключ. При перезагрузке страницы поле потребуется заполнить снова.

Обзор API

Период применяется к сводке и выгрузке событий. Время вводится локально и передаётся API как epoch milliseconds.

Сравнение использует равный по длительности предыдущий интервал. Проценты при нулевой базе не рассчитываются.
