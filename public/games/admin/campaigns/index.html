CAMPAIGN CONTROL / 01

Публикация.
Под контролем.

Управление спонсорскими кампаниями OSGARD PLAY. Сначала черновик и проверка ссылки, затем ограниченная публикация в каталоге.

Безопасное состояние

Рекламные сети и покупки здесь не включаются. Публичный слот скрыт, пока Commerce API не настроен и нет активной одобренной кампании.

Максимум 3 активных карточки. Метрики — только согласованные события реальной видимости и перехода за последние 30 дней.

01 / ACCESS

Доступ оператора

API не проверен

Токен хранится только в памяти этой вкладки, не сохраняется в localStorage и не отправляется, пока не подтверждён HTTPS API endpoint из commerce-config.json.

Для работы нужны настроенный Commerce API, PostgreSQL и токен не короче 32 символов.

02 / EDITOR

Кампания

Новый черновик

Для атрибуции интерфейс добавит UTM-параметры при переходе. Исходный URL не должен содержать токены, персональные данные или готовые tracking-параметры.

Публикация разрешена для слота «Каталог» или экрана между игровыми сессиями. Для активного статуса нужны корректные даты, включающие текущий момент. «Событие в игре» остаётся закрытым до отдельной проверки точки интеграции.

03 / INVENTORY

Инвентарь кампаний

События показа и клика поступают только после согласия на аналитику. UTM-переход сам по себе не означает покупку или подтверждённую конверсию.

Подключите API, чтобы загрузить кампании. Пустое состояние не является ошибкой.
