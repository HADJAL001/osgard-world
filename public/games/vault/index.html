OSGARD PLAY / PLAYER OWNERSHIP

Твои миры.
Твои данные.

Сохраняй поддерживаемый локальный прогресс в переносимый файл и восстанавливай его на другом устройстве. Без аккаунта, скрытой отправки на сервер и передачи ключей доступа.

LOCAL FIRST / СНАЧАЛА У ТЕБЯ

Этот инструмент читает только явно разрешённые игровые записи на текущем домене. Он не сканирует другие сайты, не подключается к API и не меняет данные до подтверждённого восстановления.

Только локальная обработка

01 / INVENTORY

Локальные сохранения

Показываем только поддерживаемые записи. Неизвестные ключи, настройки согласия, токены, платёжные данные и временные сессии не включаются в резервную копию.

Проверяем хранилище…
SUPPORTED ITEMS—поддерживаемых записей
SKIPPED—повреждённых значений
TRANSFER MODELOCALбез серверного запроса

Резервная копия — обычный JSON-файл, не зашифрованный архив.

02 / VERIFIED RESTORE

Проверить и восстановить

Файл сначала проверяется и показывается списком. До нажатия кнопки восстановления локальные данные не изменяются.

01. Выбери файл

Поддерживается файл OSGARD PLAYER VAULT v1 размером до 1 MiB. Контрольная сумма SHA-256 проверяет случайное повреждение, но не подтверждает автора файла.

Файл ещё не проверен

Выберите JSON-файл, чтобы проверить его перед восстановлением.

02. Подтверди перенос

Если на устройстве уже есть поддерживаемые данные, сначала обязательно скачай резервную копию именно текущего состояния. Это помогает вернуть прежний прогресс при ошибке или выборе не того файла.

Не заменяем неизвестные данные

Восстанавливаются только записи из проверенного файла. Остальные ключи не удаляются. Вход, согласия, аналитика, приглашения и платежи не переносятся.

Сначала выберите файл.

03 / HONEST SCOPE

Что входит в Vault

Поддержка определяется реальными адаптерами, а не количеством игр в каталоге. Остальные игровые миры могут использовать собственное хранилище, сервер или IndexedDB и этим инструментом пока не резервируются.

Каталог OSGARD PLAY

Избранные игры, если они сохранены в этом браузере.

INHERIT

Локальное состояние мира, отметки пути, имя автора и последнее отмеченное поколение. Перед импортом поля мира проходят строгую проверку.

SIGNAL RUN

Дневная серия и сохранённые результаты, у которых дата и число проходят валидацию.

04 / PRIVACY & SAFETY

Твои данные остаются у тебя

Никакой загрузки

Файл создаётся и читается внутри вкладки. Нет запросов к API, аналитике или рекламным системам.

Секреты исключены

Токены, настройки согласия, очереди аналитики, коды приглашений, параметры API и sessionStorage находятся вне разрешённого списка.

JSON не зашифрован

В файле могут быть твой локальный мир и имя автора. Не публикуй его открыто; после переноса удали ненужные копии.
