# SIGNAL RUN

Браузерная аркада OSGARD PLAY по адресу `/games/signal-run/`.

## Управление
- Стрелки влево/вправо или A/D — сменить полосу.
- Q или кнопка «Импульс» — убрать близкие помехи и получить короткий щит.
- Space — импульс во время игры, запуск на стартовом экране.
- Enter — запуск/пауза.
- На телефоне используй крупные экранные кнопки.

Три столкновения завершают забег. Световые фрагменты добавляют очки. Рекорд хранится только в localStorage текущего браузера.

## Интеграция и приватность
- Только локальные HTML/JavaScript/CSS/Canvas, без внешних библиотек и скачиваемых ресурсов.
- Совместимо с игровой оболочкой OSGARD через сообщения одного origin: ready, started, paused, resumed, completed.
- Нет сетевого рейтинга, покупок, рекламного SDK или автоматической отправки персональных данных.
- Учитывает prefers-reduced-motion.
