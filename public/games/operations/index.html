Что считается проверкой

Критический маршрут проходит, если HTTP-ответ совпадает с контрактом и содержит ожидаемый маркер страницы. Защищённая аналитика проверяется без токена: корректный ответ — JSON HTTP 401 или 403, не HTML-заглушка. Медиана и P95 рассчитываются только по завершившимся маршрутам; отменённые запросы не искажают задержки.

Экономика и коммерческие интеграции

Пустой адрес Commerce API отображается как предупреждение, а не как выручка или работающая оплата. Калькулятор монетизации — сценарная модель, не фактическая аналитика. Реклама и checkout проверяются отдельно после подключения провайдера. Сравнение запусков хранится только в памяти текущей вкладки и исчезает после перезагрузки; отчёт JSON можно скачать для дальнейшего анализа.
