# SkillCred landing — разработка и публикация

Страница: https://osgard.world/skillcred/
API: https://skillcred-pilot-api.onrender.com; браузер обращается через /skillcred-api/ на том же домене.

## Концепция

Визуальная метафора — нить доверия: непрерывная линия связывает издателя, человека и проверяющего. Она проходит через первый экран, контраст проблемы, таймлайн, живой инспектор подписи и финальный CTA.

Центральный инструмент — живая шкала проверки: JCS → Ed25519 → статус → результат. На шкале измеряется полное время ответа API от браузера до ответа сервера. Внутренние времена криптографических этапов не выдумываются и отдельно не отображаются.

## Файлы

- public/skillcred/index.html — семь актов страницы, интерактивное демо, центральный артефакт, инспектор JSON-LD, журнал запросов.
- public/skillcred/styles.css — переменные дизайна, мобильная адаптация, типографика, состояния, анимации и reduced motion.
- public/skillcred/app.js — vanilla JS: реальные запросы issue / verify / revoke, начальная демонстрация, временная шкала, инспектор JSON, журнал, FAQ, кодовые вкладки.
- public/skillcred/fonts/InterVariable.woff2 — основной шрифт.
- public/skillcred/fonts/InstrumentSerif-Italic.woff2 — шрифт для коротких акцентов.
- public/skillcred/fonts/JetBrainsMono-Regular.woff2 — технические метки, HTTP-ответы, код и время.
- public/skillcred/fonts/OFL.txt и FONT-NOTICES.txt — лицензия и уведомления о шрифтах.
- nginx.conf — тот же API-прокси и локальное кеширование CSS, JS и шрифтов.
- scripts/skillcred-page-smoke.mjs — проверка структуры, локальных шрифтов, ключевых артефактов и API-путей.

## Локальная разработка

Запустить npm ci, затем npm run dev. Vite проксирует /skillcred-api на существующий сервис SkillCred.

Демо-токен держать только в серверном окружении. Не переносить секреты издателя в HTML, CSS или JavaScript.

## Проверки перед публикацией

1. npm run check
2. npm run build
3. npm run qa:skillcred
4. npm run qa:production-routes

Публикация выполняется штатным workflow OSGARD frontend deploy. Он минифицирует CSS/JS, готовит gzip-файлы, проверяет маршруты и выполняет интеграционный цикл issue → verify → revoke → verify. После успешного деплоя Lighthouse workflow проверяет мобильный и десктопный режимы.

## Честные оговорки

- Первый экран пытается выпустить синтетическое удостоверение и проверить его на сервере. Если API недоступно, зелёная печать VALID не показывается.
- Замер на шкале — настоящий round-trip в браузере, а не выдуманные миллисекунды внутренней работы API.
- Отзыв не отменяет математическую подпись. Проверяющая сторона должна учесть и подпись, и статус.
- SkillCred 0.3.0 остаётся экспериментальным пилотом; страница не заявляет сертификацию 1EdTech или production-readiness.
- Не добавлены внешние CDN, аналитика, отслеживающие пиксели или ввод реальных персональных данных.
